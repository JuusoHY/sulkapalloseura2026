# Sulkapalloseura

Sovelluksessa käyttäjät pystyvät etsimään peliseuraa sulkapalloon. Ilmoituksessa kerrotaan, missä ja milloin pelivuoro järjestetään sekä kuinka monta pelaajaa tarvitaan.

- Käyttäjä pystyy luomaan tunnuksen ja kirjautumaan sisään sovellukseen.
- Käyttäjä pystyy lisäämään ilmoituksia sekä muokkaamaan ja poistamaan omia ilmoituksiaan.
- Käyttäjä näkee sekä omat että muiden käyttäjien lisäämät ilmoitukset.
- Käyttäjä pystyy etsimään ilmoituksia hakusanalla.
- Käyttäjäsivu näyttää käyttäjän lisäämien ilmoitusten määrän sekä listan hänen ilmoituksistaan.
- Käyttäjä pystyy valitsemaan ilmoitukselle seuraavia luokitteluja:
  - Pelipaikka: esimerkiksi Kumpula Unisport tai Otaniemi Unisport.
  - Pelaajan taso: aloittelija, keskitaso tai edistynyt.
- Käyttäjä pystyy lähettämään viestejä omiin ja muiden käyttäjien ilmoituksiin. Ilmoitussivulla näytetään käyttäjien lähettämät viestit.

Sovelluksen pääasiallinen tietokohde on **pelivuoroilmoitus** ja toissijainen tietokohde on **ilmoitukseen liittyvä viesti**.
